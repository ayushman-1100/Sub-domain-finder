# 🔍 Fast Subdomain Finder (Wordlist Based)

A **fast, simple and powerful subdomain finder tool** written in Python.  
This tool uses a **wordlist-based approach** and is optimized to run smoothly on **Termux / Android devices**.

---

SCRIPT BY ayushman

## 🚀 Features

- ✅ Wordlist based subdomain discovery  
- ⚡ Fast scanning using multithreading  
- 🧠 Auto wordlist selection (Press Enter for default)  
- 📱 Fully compatible with Termux  
- 🧑‍💻 Beginner friendly & clean code  
- 🔐 Made for Ethical Hacking & Learning
